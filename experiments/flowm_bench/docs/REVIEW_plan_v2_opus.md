## BLOCKERS
B1. PR1's premise fails. Window-level masked-FFT correlation sums every digit in the window and loses the spatial selectivity that KWM's Lucas-Kanade (LK) gets from per-pixel estimates + coherence weights. No-learning test on K-real (shared untrained conv_u imprint, 30 frames): closest-node velocity error median LK 0.06–0.08 px/frame (33–43% digits unlocked) vs literal PR1 (lags 1/2/4, multi-peak, Newton, robust fit, running mean) 0.20–0.24 (73–83% unlocked); fixed lattice 0.40–0.44. Even 1–2 digits: PR1 worse (0.025 vs 0.006; 0.057 vs 0.023). Realistic scenes: a digit's true displacement is a local max of the window surface only 33–44% of the time; even restricted to ±1.5 px around truth, median error 1.0/0.57/0.29/0.13 at lags 1/2/4/8 (bias ~1 px from other digits). Two digits one cell Δv=0.8: resolved 0/40 lag1, 0/40 lag2, 16/40 lag4, 38/40 lag8. Assignment ceiling: only 0.8% digits cannot get their own node (problem is estimator, not lattice), but 40% of sequences have a same-cell pair → needs real assignment, not greedy nearest peak. conv_u circular padding on the 32 window hurts partly visible digits (0.11 vs 0.03 with pixels). Fix: spatially selective estimator (local cost volume per pixel over the node's residual range, Gaussian-aggregated, pooled per node with KWM coherence weights; or local-search lock then multi-lag LK refine); per-sample snapshots with analytic camera compensation instead of a per-node bank; NO-LEARNING GATE before any GPU run: beat untrained LK on 300 K-real sequences on both closest-node and one-to-one matched error; add a 25-node oracle (KWM's oracle has V=n_digits+1=6 nodes, so 0.006 is not a pure velocity ceiling).
B2. Budget/memory. Matrix is 80 runs not 40; PR4, relaxed control, K-int, anchor runs unbudgeted; `--preset flowm` anchor costs 11–22x a default run; realistic 1700–3000 GPU-h vs 570 planned. Unmodified KWM adaptive at B=16×50 steps ≈ 27 GiB (CPU saved-tensor estimate) > ~22 GB free → needs --accum/--grad_ckpt. Per-node imprint bank for lags adds 12–25 GiB. PR1 as written adds ~60% step time (full adaptive step 508 ms CPU B=16; correlation 96 ms + bank transport 114 ms + Newton 90 ms). Fix: 200-step GPU benchmark per arm as gate; recount; factorial only where interaction hypothesised; anchor = FloWM + best arm 1 seed or drop; screen 2–3 seeds, 5 only for primaries.
